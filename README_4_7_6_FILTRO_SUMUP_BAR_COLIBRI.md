# COLIBRÍ ERP 4.7.6 · Filtro de cuenta SumUp

La conciliación de cobros procesa exclusivamente las operaciones cuya columna **Cuenta** corresponde a **Bar Colibri**.

Se admiten variantes normalizadas: Bar Colibri, Bar El Colibri y Brasería El Colibrí.

Las operaciones de otras cuentas, como APP AMADOR, se excluyen antes de realizar cualquier cruce con Numier. La pantalla informa del número de operaciones descartadas y de la cuenta de origen.
