# COLIBRÍ ERP 4.7.3 · Gastos Numier G

Los registros de cabecera con estado `G` continúan excluidos de ventas e IVA, pero se incluyen como gasto real y restan del beneficio del periodo.

Afecta a Resultado real, Inteligencia, Dashboard, Centro de mando, Centro de decisiones y Gestoría. Los informes Excel y PDF muestran el importe separado como **Gastos Numier (G)**.
