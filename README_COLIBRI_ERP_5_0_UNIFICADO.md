# COLIBRÍ ERP 5.0 · ERP UNIFICADO

## Objetivo
Reducir la navegación principal a ocho áreas sin eliminar funciones ni fuentes de datos.

## Áreas
- Inicio: Resumen + Pendientes y decisiones.
- Operación: En directo + TPV + Conciliación + Caja + Cierres.
- Finanzas: Resultado real + Productos/costes + Facturas + Escandallos + Márgenes + Proveedores.
- Personal: Ahora + Plantilla + Puntualidad + Historial + Cuadrante + Comparador.
- Gestoría.
- Análisis: Inteligencia + Asistente IA.
- Almacén.
- Configuración.

## Compatibilidad
Las rutas internas antiguas se normalizan hacia las nuevas áreas para conservar los accesos desde Dashboard, Centro de decisiones y otros componentes. Los componentes existentes siguen siendo la fuente de funcionalidad; esta versión reorganiza la navegación sin eliminar módulos.

## Criterios visuales
Pestañas opacas, alto contraste, una única jerarquía de navegación y menú móvil hamburguesa con solo las áreas principales.
