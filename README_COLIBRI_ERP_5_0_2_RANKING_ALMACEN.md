# COLIBRÍ ERP 5.0.2 · Ranking de Almacén

- Ranking de artículos vendidos por día o rango de fechas.
- Orden por unidades, facturación o beneficio.
- Buscador por producto/código.
- Edición de coste unitario desde el ranking.
- Se mantiene coste provisional automático de 1/3 del PVP si no existe coste configurado.
- Productos del ranking pulsables con detalle de unidades, ventas, PVP, coste, beneficio y margen.
- KPIs principales de Almacén pulsables con acceso al detalle/configuración.
- Diseño responsive y alto contraste.
