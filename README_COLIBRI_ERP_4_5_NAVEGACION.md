# COLIBRÍ ERP 4.5 — Navegación y diseño unificado

## Cambios
- Navegación reorganizada por áreas: Inicio, Operación, Finanzas, Personal, Control y análisis, Sistema.
- Menú móvil hamburguesa con panel lateral, overlay, cierre exterior y selección automática.
- Barra lateral de escritorio agrupada y más clara.
- Fichajes vuelve a estar accesible desde el centro de Personal.
- Sistema visual reforzado: fondos claros opacos, texto oscuro, botones sólidos, controles legibles, tablas y modales con contraste.
- Se mantienen todos los módulos y rutas internas existentes.
- El portal `fichar` permanece separado y no recibe los estilos del shell de gerencia.
